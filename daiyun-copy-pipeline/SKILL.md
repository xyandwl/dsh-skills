# 短视频代运营文案流水线（多角色审查）

面向「本地服务多行业」的短视频文案生成与审查工作流。目标：把客户资料转化为可用于拍摄、巨量本地推投流、获客、提升营业额的文案，并通过多角色审查保证转化力与合规性。

## 目录约定

工作目录 `D:\代运营工作流\`（若不存在，则用当前工作区；已有同名目录时两处取 D 盘为准）。
客户目录 `clients\<客户名>\`：

- `客户信息.md`：行业、卖点、目标人群、门店/服务、客单价、优惠、风格、投放目标
- `原始资料\`：客户提供的 Word / PDF / 图片截图 / 文本
- `策略卡\`：投手策略卡（`<日期>-策略卡.md`）
- `文案\`：终稿文案（`<日期>-文案.md`）
- `脚本\`：拍摄分镜（`<日期>-拍摄脚本.md`）
- `投流建议\`：投流/本地推投放建议（`<日期>-投流建议.md`）

可复用 `D:\代运营工作流\scripts\` 下的 `materials_reader.py`（读资料）、`md_to_docx.py`（转 Word）等既有脚本。

## 四个角色

1. **策略操盘手（行业运营投手）**：定方向，从投流、获客、营业额角度产出「策略卡」。
2. **文案主笔**：写初稿。支持 AI 生成 与 用户贴稿 两种模式。
3. **文案审查者**：审转化力与质量（钩子、口语化、卖点、节奏、CTA）。
4. **违规审查者**：审合规（广告法禁词、平台违禁、夸大宣传、行业特殊禁忌）。

## 流水线（六步）

### 步骤 0：读资料
读 `客户信息.md` 与 `原始资料\` 下全部文件（.txt/.md/.csv 直读；.docx 用 python-docx；.pdf 用 pypdf；图片用视觉模型识图，失败退回 OCR）。
- 客户资料优先读 `原始资料\`，**不让用户手工粘贴**。
- 缺失关键信息（行业/人群/卖点/客单价/投放目标）逐条追问，禁止编造。

### 步骤 1：策略操盘手 → 策略卡
产出策略卡，至少包含：
- **行业与人群**：所属行业、目标人群画像（年龄/性别/地域/场景/需求）
- **核心卖点**：3 个可投放卖点（区分「客户给的」与【假设·待确认】）
- **痛点与钩子方向**：目标人群痛点 + 3 个钩子方向（制造好奇/戳痛点/给结果/反常识/限时福利）
- **获客路径**：看到→停留→点击→私信/领券→到店 的转化链路，以及文案要埋的引导动作（评论区/私信/团购卡券/门店地址）
- **投放策略**：本地推定向（商圈/距离/人群包）、素材方向（口播/实拍/图文）、预算出价建议（按目标分档：曝光/进店/成交）
- **文案方向**：本期数量、字数（145–180 字/条）、风格、口吻

保存到 `clients\<客户>\策略卡\<日期>-策略卡.md`。
> 用户未确认策略卡前，停下等用户回「确认」。

### 步骤 2：文案主笔 → 初稿
两种模式：
- **AI 生成**：按策略卡生成 N 条口播文案初稿 + 标题 + 话题标签。
- **用户贴稿**：用户贴进自写稿，跳过生成，直接进入审查。

文案要求：口语化、有钩子、符合抖音调性、每条 145–180 字、有明确 CTA。

### 步骤 3：文案审查者 → 转化审查
逐条审查，输出「审查意见表」：
文案编号｜钩子强度｜口语化｜卖点清晰｜节奏/完播｜CTA 明确｜问题定位｜修改建议｜结论（通过/需改/重写）。

### 步骤 4：违规审查者 → 合规审查
逐条审查，输出「合规报告」：
违规词/表述｜违规类型（广告法/平台违禁/夸大宣传/行业禁忌）｜风险等级（高/中/低）｜替换建议。

重点覆盖（本地服务多行业）：
- **广告法极限词**：最、第一、国家级、顶级、100%、根治、无副作用、纯天然等
- **夸大承诺**：保证效果、绝对有效、包治、稳赚不赔、无效退款（无依据时）
- **行业特殊禁忌**：
  - 医美/医疗：疗效承诺、患者案例、术前术后对比、"安全无痛"
  - 教培：提分/保过承诺、名师唯一、升学保证
  - 金融/借贷：保本保收益、低息无风险、稳赚
  - 餐饮/食品：涉及疾病预防治疗功能
  - 美业/健身：减肥承诺、"7天见效""不反弹"
- **平台违禁**：引导站外交易、绝对化诱导点击、虚假限时/虚假库存

### 步骤 5：改稿 → 终稿
文案主笔综合两份审查意见逐条修改，输出终稿，每条后附「改动说明」（改了哪里、为什么）。改后重新过一遍违规审查确认合规。

### 步骤 6：交付三件套
1. **口播文案 + 标题 + 话题标签** → `文案\<日期>-文案.md`
2. **拍摄分镜脚本** → `脚本\<日期>-拍摄脚本.md`：镜号｜景别｜画面内容｜台词/字幕｜时长（秒）｜运镜｜备注，附道具清单与拍摄提示
3. **投流/本地推投放建议** → `投流建议\<日期>-投流建议.md`：定向（商圈/距离/人群）、出价与预算（按目标分档）、素材方向、投放节奏、A/B 测试建议

## 注意
- 分镜统一在步骤 6 产出，文案任务不重复输出分镜。
- 需要 Word 交付版可用 `scripts\md_to_docx.py` 或 office-docx skill。
- 缺失信息必须追问，禁止编造；不确定的卖点标【假设·待确认】。
