# 爆款潜力评分卡

交付前打分。**总分 < 60 不交付**：直接说明短板并给重写版。

## 四项打分（各 25 分）

### A. 钩子强度（25）

| 分值 | 标准 |
| --- | --- |
| 21–25 | 前两句有具体冲突或反常识结论，目标人群 1 秒内认领 |
| 16–20 | 有钩子但偏通用，换个人群也能用 |
| 11–15 | 前两句在铺垫（背景、心情、问候） |
| 0–10 | 开头是自我介绍或“今天聊聊” |

自检问：把首句发给一个陌生人，他会问“然后呢？”吗？

### B. 信息增量（25）

| 分值 | 标准 |
| --- | --- |
| 21–25 | 有 3 个以上别处抄不到的具体细节（数字/型号/顺序/代价） |
| 16–20 | 有 1–2 个具体细节，其余是常识 |
| 11–15 | 全是形容词与通用建议 |
| 0–10 | 通篇情绪，无可执行内容 |

自检问：读者照做，能不能产生一个可观察的变化？

### C. 传播动机（25）

| 分值 | 标准 |
| --- | --- |
| 21–25 | 有明确社交货币：替人说话 / 可用工具 / 稀缺信息 / 身份认同 |
| 16–20 | 有用但“只对自己有用”，不一定会转 |
| 11–15 | 私密性强或过于平淡 |
| 0–10 | 广告感强，转发会掉面子 |

自检问：读者转发时，会配一句什么话？说不出 → 传播动机不足。

### D. 结构与合规（25）

| 分值 | 标准 |
| --- | --- |
| 21–25 | 平台结构完整、分段合理、有互动收口、零合规风险 |
| 16–20 | 结构基本对，缺互动或某段偏长 |
| 11–15 | 未按平台节奏分段 / 有 1 处限流词 |
| 0–10 | 有疗效承诺、导流词、极限词 |

## 加分项（各 +3，上限 +12）

- 有真实数据或可验证对比
- 有系列化钩子（“第 N 篇”“合集”）
- 反常识观点有依据
- 结尾动作门槛极低（扣 1、选 A/B）

## 减分项

| 问题 | 扣分 |
| --- | --- |
| 一条内容讲 3 个不相关主题 | −8 |
| 标题承诺正文未兑现 | −10 |
| 出现“希望对你有帮助”“让我们一起” | −5 |
| 出现极限词/导流词 | 直接判不通过 |
| 全文没有任何数字 | −5 |

## 交付时怎么报分

只报四项分 + 一句结论 + 一条改法，不写长篇点评：

```
钩子 22 · 增量 18 · 传播 16 · 结构 21 = 77 / 100
结论：能发。短板在传播动机——内容偏“只对自己有用”。
改法：把第 3 点改成“可以转给同事的一句话版本”，并在结尾抛 A/B 选择。
```

## 迭代优先级（分数低时按这个顺序改）

1. 改钩子（首句）→ 提升最大，成本最低
2. 加一个具体数字或对比 → 提升可信度
3. 砍到只讲一个点 → 提升完播/完读
4. 加低门槛互动 → 提升评论
5. 调封面主标 → 提升点击率（平台相关）
