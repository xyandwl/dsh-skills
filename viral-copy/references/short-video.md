# 短视频脚本（抖音 / 视频号 / 快手）

## 平台逻辑

- 完播率是第一指标，**前 3 秒**决定 80% 的完播。
- 点赞 < 评论 < 转发 < 收藏（不同赛道略有差异，但“让人想转给朋友”永远最值钱）。
- 口播类成本最低、可批量、最适合知识/经验号。
- 视频号靠社交推荐（朋友点赞会推给好友），所以**“愿意公开点赞”**是选题标准：太私密的内容没人敢点。

## 3 秒钩子（六种，按赛道选）

| 类型 | 首句模板 | 适合 |
| --- | --- | --- |
| 结论前置 | 「先给结论：{反常识结论}」 | 知识、测评 |
| 点名 | 「{身份} 刷到这条先别划走」 | 垂类干货 |
| 代价 | 「{做法} 一年让我多花了 {N} 块」 | 理财、消费 |
| 反常识 | 「{公认做法} 其实是错的」 | 通用 |
| 冲突现场 | 「（画面：被退回的方案）这是我第 4 版」 | 职场、情感 |
| 结果展示 | 「（画面：前后对比）3 周，就改了这一件事」 | 健身、美妆、改造 |

**前 3 秒禁忌**：自我介绍、问候语、“今天我们来聊聊”、Logo 动画、字幕还没出就说正文。

## 口播稿结构（60 秒 ≈ 220–260 字）

```
0–3s   钩子：一句话制造缺口或点名
3–8s   立信：凭什么听你说（一句经历/一个数字）
8–35s  主体：3 点，每点 1 句结论 + 1 句细节
35–50s 反驳/反常识：拆掉一个常见误解
50–60s 收口：一句可执行动作 + 一句关注引导
```

不要写“大家好我是…”。如果你必须介绍自己，把它放到第 20 秒的立信句里。

### 60 秒口播稿模板

```
（钩子）如果你也是每天坐 9 小时的人，这条能救你的腰。
（立信）我做过 3 年设计，腰间盘轻度突出，试过 11 个方法。
（主体）真正有用的只有 3 个。
 第一，每小时起来 2 分钟，不是拉伸，是靠墙站，让骨盆回到中立位。
 第二，椅子别调高，膝盖略低于髋，腰自然就贴住靠背。
 第三，别用腰枕，用卷起来的毛巾，位置在腰眼而不是腰中。
（反驳）很多人买 300 块的护腰，其实它只是提醒你别塌腰，不解决肌肉问题。
（收口）今天先做第一条，2 分钟，下班前做 3 次。想要完整清单，评论区扣「腰」。
```

## 分镜表（交付时必须给）

| 时间 | 画面 | 口播 | 字幕/花字 |
| --- | --- | --- | --- |
| 0–3s | 近景，人正对镜头，情绪紧 | 如果你也每天坐 9 小时 | 大字：坐 9 小时的人 |
| 3–8s | 切侧身，示范坐姿 | 我腰间盘轻度突出 | 小字：3 年设计 |
| … | … | … | … |

画面栏只写**能拍到的动作**，不写“氛围感”“高级感”这类无法执行的描述。

## 节奏与字幕

- 每 3–5 秒一次画面变化（切镜/推拉/加花字/换机位），否则完播掉。
- 关键结论必须**上字幕**，且字号大（手机屏 1/10 高度）。
- 数字加花字强调：`3 次` `2 分钟` `300 块`。
- 语速 5–6 字/秒，句尾下沉，不用“呃、那个”。
- 结尾 3 秒不要放“感谢观看”，直接给动作或抛问题。

## 封面与标题

- 竖屏 3:4 或 9:16 首帧，**首帧就是封面**：一个字大结论 + 一张有信息量的画面。
- 标题（20 字内）与口播第一句**不要完全一样**，两者互补：标题给结论，口播给缺口。
- 常见有效标题：`{身份}+{痛点}+{反常识}`，如 `久坐的人别再拉伸了，先做这 2 分钟`。

## 常见翻车点

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 前 3 秒完播低 | 开场是问候/铺垫 | 把结论或冲突提到第一句 |
| 中间掉量 | 3 点讲成 3 段独白，无变化 | 每点配一次画面变化+花字 |
| 转发少 | 内容太私密或太泛 | 改成“值得转给同事/朋友”的角度 |
| 评论少 | 结尾没有低门槛动作 | 加“扣 1 / 你选哪条” |
| 被判低质 | 搬运、纯口播无增量 | 每 10 秒至少一个新信息 |
