# 抖音博主作品盘点

给一个博主，拿到她的**作品全表**（带互动数据），按数据挑出值得拆的几条。

## 前置（缺一不可）

1. **抖音登录态**：`%APPDATA%\dsh-desktop\harness\douyin-duty\douyin_cookie.txt` 里要有 `sessionid`
   —— 由 `dsh-douyin-scroll` 插件（设置 → 刷抖音 → 扫码登录）维护。
2. **签名器**：`dsh-douyin-scroll` 插件自带 `tools/dy-signer.mjs`（抖音 web 的 `a_bogus` 签名）。
   插件默认路径 `D:\dsh-plugins\dsh-douyin-scroll`，可用环境变量 `DOUYIN_PLUGIN_DIR` 覆盖。

## 用法

```bash
node scripts/creator-posts.mjs --input "<主页链接 | v.douyin.com 短链 | sec_uid | 单条视频链接>" \
     [--pages 2] [--top 10] [--json out.json]
```

- `--pages`：翻几页（每页 20 条，默认 2，上限 15）
- `--top`：输出两个榜单各取前几条（默认 10）
- `--json`：把完整结果（含全部作品）写到文件

输出两个榜：

- **按点赞 Top**——这条账号的"绝对爆款"
- **按分享率 Top**（分享/点赞）——"最想转给别人看"的内容，通常才是真正可抄的结构

## 判读要点

| 指标 | 正常区间 | 偏离意味着 |
|---|---|---|
| 分享/点赞 | 0.05–0.2 | >0.5：身份认同/羡慕型内容，转发是主驱动；<0.05：干货或娱乐型 |
| 收藏/点赞 | 0.1–0.3 | >0.5：教程/工具型，值得抄"清单感" |
| 评论/点赞 | 0.02–0.1 | 明显高：有争议或强互动话术 |

**别只看点赞绝对值**：一条 5 万赞但分享率 0.05 的，参考价值低于一条 1000 赞、分享率 0.9 的——后者说明"结构让人想转"。

## 拿到列表之后

挑 2–5 条，走后续两步（各自的技能）：

1. **扒文案**：`douyin-video-copy`（单条链接 → 标题/数据/章节要点/口播逐字稿，本地 ASR，免费）
2. **拆结构**：`viral-video-teardown-remake` 的拆解层（钩子/中段/转化、骨架复用；纯文本拆解不扣费）

建议产出落到 `D:\代运营\内部\对标拆解\<博主名>\`，一条一份，外加一份"账号级共性总结"。

## 边界与风控

- 只读**公开**作品；私密、好友可见、已删除的拿不到。
- 走网页签名接口，**不要高频轮询**：默认每次 1–2 页，页间已内置 1.5 秒间隔；批量盘点多个博主时，博主之间至少隔 1 分钟。
- 返回的 `digg/comment/collect/share` 是读取时快照，随时间会变；报告里要写抓取时间。
- 拿不到播放量（抖音不返回），所以**完播率相关的判断只能靠互动结构推断**，报告里必须说明。
