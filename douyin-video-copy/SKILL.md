# 扒抖音文案

输入一条公开抖音视频的分享链接，输出四样东西：

1. **标题 / 作者 / 数据 / 发布时间**（公开字段）；
2. **章节要点**——抖音自己的 AI 摘要，带时间轴，**通常已经把全篇结构说清楚了，这是最准的一路**；
3. **口播草稿**——抓音频到本地做语音识别，粗稿（同音字会错，念之前要顺）；
4. **视频/音频直链**（带签名，几小时有效，要存当场存）。

## 依赖（本机已装好）

- Python：`%USERPROFILE%\.local\lib\python312\python.exe`（已装 websocket-client、vosk、faster-whisper）
- 浏览器：本机 Edge（脚本自动找两个 Program Files 路径）
- 转码：`C:\Users\徐彦\ffmpeg\bin\ffmpeg.exe`
- 中文语音模型：`C:\dsh-asr\vosk-cn`（43 MB，纯 ASCII 路径）
  ⚠️ Vosk 读不了带中文的路径（`C:\Users\徐彦\...` 会报 model files 缺失），脚本会自动把非 ASCII 路径拷到 `C:\dsh-asr` 再用。

## 怎么用

脚本：`dy_copy.py`

```powershell
$py = "$env:USERPROFILE\.local\lib\python312\python.exe"
$s  = "<本技能目录>\dy_copy.py"

& $py $s all     "https://v.douyin.com/xxxxxx/" --out "C:\某目录\dy-1"     # 全流程
& $py $s extract "https://v.douyin.com/xxxxxx/" --json                     # 只要信息（5–10 秒）
& $py $s download "https://v.douyin.com/xxxxxx/" --out "C:\某目录" --video  # 只要文件
& $py $s asr     "C:\某目录\audio.mp4"                                      # 已有文件，只转写
```

`all` 在输出目录生成 `douyin-copy.md`：标题、数据、章节要点、口播草稿一次给全。

## 拿到结果后怎么用（重要）

1. **先看章节要点**。有内容，就以它为准做拆解、抄骨架、写选题——结构、时间轴、观点都在里面。
2. **口播草稿只当参考**。Vosk 小模型对普通话清楚的口播能到七八成，但**同音字、专有名词、数字几乎必错**（“B端”会被听成“弊端”，“IP”听成“挨批”）。数字和结论必须回原文核。
3. **草稿要过一遍模型整理**：让模型按原意顺成通顺口播（不许加内容、不许改观点），再用于二创参考。
4. 章节要点为空（冷门视频常见）→ 只能靠口播草稿 + 封面/字幕。

## 已知边界

- 只能读**公开视频**；私密、好友可见、已删除的抓不到。
- 抖音有反爬，偶尔返回空页面：重试一次，仍失败就 `--wait 12` 调大等待；别并发开一堆浏览器。
- 直链带签名，几小时后失效。
- 长视频（10 分钟以上）ASR 会慢，Vosk 大约 1 分钟音频跑 3–5 秒。

## 合规

只用于公开内容的拆解学习、竞品研究、选题参考。整段搬运、去水印二次发布、冒用他人文案，平台明确打击，别做。
